# FlashLabs Chroma - Voice AI Demo

This Space runs the Chroma 4B multimodal AI model for spoken dialogue with voice cloning.

## Features

- **Speech Understanding**: Upload audio and get AI responses
- **Voice Cloning**: Choose from multiple voice styles
- **Real-time Generation**: Fast inference with GPU acceleration

## Usage

1. Upload an audio file (WAV format recommended)
2. Select a voice style for the response
3. Click "Generate Response"
4. Listen to or download the AI's audio response

## API Access

This Space also exposes a REST API. See the API documentation at `/docs`.
